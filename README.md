# Likith G — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages; no build step or package installation is needed.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.

## Personal details to update

- Social links and email are in `index.html`.
- Project cards, live-site links, and GitHub links are in `index.html`.
- Replace `assets/profile.png` with your new profile photo whenever it is ready. Keep the same filename to update the website automatically.
- The photography archive is in `photography.html`. Add your photos or video thumbnails to `assets/` and replace the gallery placeholders there when you’re ready.
- Images live in `assets/`.

## Publish with GitHub Pages

1. Push these files to the repository’s default branch.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose the default branch and the `/ (root)` folder.
4. Save. GitHub will provide the public portfolio URL.
